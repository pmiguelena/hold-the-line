Type the same shock code on the level screen and every student faces identical events. Mismo código, mismos shocks.

What it teaches

Lags, expectations and credibility, the zero lower bound, forward guidance, central bank independence, financial conditions. Rezagos, expectativas, independencia.

No accounts, no installs

It runs in any browser, on phones too. Progress stays in each student's browser. Funciona en cualquier navegador.

Based on a New Keynesian model first built in R Shiny (2024). Free to use in class.
